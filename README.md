# Cloud Trade — автоматический бот для Binance Futures

Бот круглосуточно сканирует 25 самых ликвидных USDT-фьючерсов Binance, ищет сигналы,
сам открывает сделки и сразу ставит на бирже стоп-лосс и тейк-профит. Дальше он
сопровождает позиции: подтягивает трейлинг-стоп и следит за лимитами риска.

> ⚠️ Торговля с плечом может привести к потере всего депозита. Результаты на истории
> не гарантируют прибыль в будущем. Запускайте на реальные деньги только после
> нескольких недель тестнета и только с суммой, которую готовы потерять.

## Стратегия

**Пробой канала Дончиана по тренду** на 4h с фильтром по дневному графику:

| | Лонг (шорт зеркально) |
|---|---|
| Тренд | Дневной график: EMA50 > EMA200 и цена выше EMA50 |
| Сила тренда | ADX(14) на 4h ≥ 20 |
| Вход | Свеча 4h закрылась выше максимума последних 55 свечей, вход по рынку |
| Стоп-лосс | 2 ATR от входа, сразу ордером на бирже |
| Тейк-профит | 3R (в 3 раза дальше стопа), сразу ордером на бирже |
| Трейлинг | Стоп подтягивается на 3 ATR от лучшей цены с момента входа |

Почему именно она: я проверял несколько подходов на истории 24 пар с 2024-01 по 2026-10.
Параметры подбирались на первой половине истории, а проверялись на второй, которую
стратегия «не видела»:

- **Вход на откате к EMA на 1h** дал −99,5% за период: слишком много сделок, комиссии съедают всё.
- **Тот же подход на 4h** дал около нуля, это хуже, чем ничего не делать.
- **Пробой канала на 4h** в плюсе в обеих половинах истории, и соседние значения параметров
  тоже в плюсе. Это признак устойчивости, а не случайной подгонки.

Итог бэктеста стратегии по умолчанию (риск 1% на сделку, до 5 позиций, комиссии 0,05%
и проскальзывание 0,02% учтены; если в одной свече задеты и стоп, и тейк, считается стоп):

| | Весь период | 1-я половина | 2-я половина |
|---|---|---|---|
| Сделок | 586 | 239 | 347 |
| Прибыльных | 34,6% | 34,3% | 34,9% |
| Profit factor | 1,15 | 1,22 | 1,12 |
| Доходность | +52,0% | +27,3% | +20,4% |
| Годовых | 15,9% | 18,6% | 14,0% |
| Макс. просадка | −24,6% | −18,4% | −24,6% |

Чего ждать: прибыльных сделок около трети, бывали серии до 21 убыточной сделки подряд и
убыточные месяцы (август–октябрь 2026: −21%). Деньги делают редкие сильные тренды.
Преимущество стратегии небольшое, поэтому риск на сделку важнее любых других настроек.

## Риск-менеджмент

- **Размер позиции:** при срабатывании стопа теряется 1% депозита (`RISK_PER_TRADE`).
- **До 5 позиций одновременно**, каждая на изолированной марже с плечом 3x. Номинал каждой
  позиции ограничен, чтобы все они вместе помещались в депозит.
- **Дневной лимит:** −3% за день, и новых сделок до следующего дня (UTC) нет.
- **Аварийная остановка:** −15% от максимума депозита, и бот перестаёт открывать сделки
  до вашей проверки. На истории просадка доходила до −24,6%, так что этот стоп может
  сработать. Это сделано намеренно: лучше остановиться и разобраться.
- **Защита позиций:** если стоп-ордер пропал с биржи, бот ставит его заново. Если поставить
  стоп не удалось, позиция сразу закрывается. Позиций без стопа не бывает.
- **Ручная пауза:** создайте пустой файл `data/STOP`, и бот перестанет открывать новые сделки.
  Открытые позиции он продолжит сопровождать.
- Позиции, открытые вручную, бот не трогает.

## Запуск

### 1. Установка

```bash
git clone https://github.com/chernikovdanila2000-tech/Cloud-Trade.git
```

```bash
cd Cloud-Trade && python3 -m venv .venv && . .venv/bin/activate && pip install -r requirements.txt
```

```bash
cp .env.example .env
```

### 2. Бэктест (проверка на истории)

```bash
python backtest.py --start 2024-01 --end 2026-10
```

История скачивается с `data.binance.vision` и кэшируется в `data/history/`.

### 3. Бумажная торговля (без ключей)

В `.env` оставьте `MODE=paper` и запустите:

```bash
python run_bot.py
```

### 4. Тестнет Binance (рекомендуется минимум 3–4 недели)

1. Зайдите на https://testnet.binancefuture.com, войдите и создайте API-ключ.
2. В `.env` укажите `MODE=testnet`, `BINANCE_API_KEY` и `BINANCE_API_SECRET`.
3. Запустите `python run_bot.py`.

### 5. Реальная торговля

1. На binance.com создайте API-ключ: только права **Futures**, **без вывода средств**,
   с **ограничением по IP** вашего сервера.
2. В `.env` укажите `MODE=live`, оба ключа, `I_UNDERSTAND_THE_RISK=yes` и `RISK_PER_TRADE=0.01`
   (или `0.005`, если хотите пережидать серии стопов спокойнее).
3. **Перед первым запуском проверьте связку с биржей.** Команда откроет позицию на ~7 USDT,
   поставит стоп-лосс и тейк-профит, проверит, что они появились на бирже, и сразу всё закроет.
   Это стоит несколько центов комиссии:

   ```bash
   python run_bot.py --check-orders
   ```

   В Docker то же самое:

   ```bash
   docker compose run --rm bot python run_bot.py --check-orders
   ```

   Запускайте бота, только если в конце написано «ПРОВЕРКА ПРОЙДЕНА». Если нет, пришлите
   мне вывод команды.

### Работа 24/7 на сервере

Бот должен работать постоянно, поэтому лучше всего подходит VPS (от ~5 $/мес).
Выбирайте сервер в Европе или Азии: Binance блокирует запросы из США и ряда других стран.

```bash
docker compose up -d --build
```

```bash
docker compose logs -f
```

Бот сам поднимется после сбоя или перезагрузки сервера. Состояние и журнал хранятся в `data/`.

### Telegram-уведомления

Создайте бота у @BotFather, а свой chat_id узнайте у @userinfobot. Затем впишите оба значения
в `.env`. Бот будет сообщать о каждой сделке, закрытии, ошибках и итогах дня.

## Структура

| Файл | Назначение |
|---|---|
| `run_bot.py` | запуск бота |
| `backtest.py` | портфельный бэктест |
| `bot/strategy.py` | сигналы стратегии |
| `bot/trader.py` | главный цикл: скан, вход, сопровождение, лимиты |
| `bot/exchange.py` | Binance через ccxt и бумажный брокер |
| `bot/risk.py` | размер позиции и лимиты |
| `bot/config.py` | все параметры |
| `tests/` | проверка, что стратегия не заглядывает в будущее |
